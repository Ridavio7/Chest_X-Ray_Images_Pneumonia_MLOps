# 1. Описание бизнес-задачи

Цель проекта — разработать автоматизированный ML-пайплайн для выявления пневмонии по рентгеновским снимкам грудной клетки с использованием методов глубокого обучения и AutoML.

Пневмония является одним из наиболее распространенных заболеваний дыхательной системы. Своевременная диагностика позволяет снизить риск осложнений и повысить эффективность лечения. Однако анализ рентгеновских снимков требует участия квалифицированных специалистов и занимает значительное время.

Использование моделей компьютерного зрения позволяет:

- ускорить процесс диагностики;
- снизить нагрузку на врачей-рентгенологов;
- уменьшить вероятность пропуска патологий;
- использовать модель как систему поддержки принятия врачебных решений;
- автоматизировать первичный скрининг пациентов.

Тип задачи машинного обучения:

**Бинарная классификация изображений**

Целевые классы:

- NORMAL — пациент здоров;
- PNEUMONIA — обнаружены признаки пневмонии.

# 8. Метрики качества

Для оценки моделей используются:

- Accuracy;
- Precision;
- Recall;
- F1-score;
- Confusion Matrix.

Особое внимание уделяется Recall.

Для медицинской задачи критически важно минимизировать количество пропущенных случаев заболевания.

Формула Recall:

Recall = TP / (TP + FN)

Высокий Recall означает, что модель обнаруживает максимальное количество пациентов с пневмонией.


Особенно важным результатом является высокий показатель Recall.

Для медицинских задач приоритетом является минимизация количества пропущенных случаев заболевания.

Модель пропустила только:

```text

```

случая пневмонии из 390 пациентов с заболеванием.

Следует отметить, что validation-набор содержит всего 16 изображений, поэтому полученные значения могут быть статистически нестабильными.

Более объективной оценкой качества является тестовая выборка из 624 изображений, на которой модель продемонстрировала Recall = 0.9923 и ROC-AUC = 0.9473, что подтверждает её способность эффективно выявлять случаи пневмонии.

# 15. Интерпретируемость модели (Grad-CAM)

Для объяснения работы модели использовался алгоритм Grad-CAM.

Grad-CAM позволяет визуализировать области изображения, которые оказали наибольшее влияние на итоговое решение нейронной сети.

Результатом работы алгоритма является тепловая карта, наложенная на исходный рентгеновский снимок.

Это позволяет:

- проверить корректность работы модели;
- убедиться, что сеть анализирует область лёгких;
- повысить доверие к модели;
- использовать результаты как элемент Explainable AI.

Модуль реализован в:

```text
src/explainability/gradcam.py
```

Запуск Grad-CAM для конкретного изображения:

```bash
python -m src.explainability.gradcam data/chest_xray/test/PNEUMONIA/person1_virus_6.jpeg
```
